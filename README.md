## Monorepo layout

- `apps/web`: Next.js + Convex web application

## Getting Started

First, run the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `apps/web/src/app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.

## AI PDF to Markdown parsing

PDF uploads are converted to markdown using `alibaba/qwen3.5-flash`, then
chunked and embedded for retrieval.

If AI parsing fails, the upload is rejected with a clear error message. There is
no local OCR fallback path in the current pipeline.
